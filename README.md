# Lulutong 的 GitHub 个人主页

这是 `lulutong` 的双语个人学习主页源代码，使用纯 HTML 和 CSS 制作，适合发布到 GitHub Pages。

## 本地预览

1. 下载或克隆本文件夹。
2. 直接双击打开 `index.html`，即可在浏览器中预览。
3. 也可以使用 VS Code 的 Live Server 等本地静态服务器预览。

## GitHub Pages 发布

1. 创建公开仓库：`lulutong-fyyyy.github.io`。
2. 将 `index.html`、`style.css` 和本 `README.md` 上传到仓库根目录。
3. 在仓库的 **Settings → Pages** 中，选择部署分支（通常是 `main`）和根目录 `/ (root)`。
4. 保存后等待 GitHub Pages 部署。
5. 主页地址应为：`https://lulutong-fyyyy.github.io/`

本网站没有包含学号、密码、token、私人联系方式或私密作业内容。
